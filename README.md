# KZGC content pack

This repository hosts the optional downloadable HD content pack for **Kivotos Zero Gravity Circuit** (KZGC), an unofficial, non-commercial fan-concept game.

It is not affiliated with Nexon, Yostar, Blue Archive, or any other rights holder. The pack contains no official or extracted game assets and no character models.

## Download

Release tag `content-v1` attaches:

- `kzgc_content_v1.pck` — the Godot resource pack (cars, buildings, furniture, interiors, and a sky panorama)
- `content_manifest.json` — version, size, SHA-256, and the pack URL the game reads on first launch

The game loads the pack with `ProjectSettings.load_resource_pack`. Play is fully possible without it; the base APK already includes a smaller kit and the Chapter 1 apartment menu.
